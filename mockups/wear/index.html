Reminders on Wear OS — v1

Nine screens, drawn at 426×426 — the real Pixel Watch 4 panel at 320 dpi, so these are hardware pixels, not a guess. Ember flow accent, Material Flow ink. Scope and rationale live in docs/wear-os.md; the build is tracked in issue #39.

Type sizes come from Wear Material 3's scale, doubled: at 320 dpi one sp is two pixels, so bodyLarge 16sp is 32 px here. An earlier pass sized the text by eye and landed near 9 sp — legible on a monitor, too small on a wrist. Read a value off this page and halve it to get the sp the code should use.
